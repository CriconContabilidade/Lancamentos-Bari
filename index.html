Cadastro — Lançamentos Padrões
De-para de palavra-chave (do histórico do extrato) → contas de débito/crédito. Deixe Débito ou Crédito em branco pra usar só a conta banco (20) nesse lado, com o outro em branco pra completar à mão. Marque "Ignorar" pra excluir do lançamento (ex.: o que já vira baixa noutra função). Clique em "+ Novo padrão" pra adicionar mais regras — esse cadastro é só desta ferramenta (Bari), não é compartilhado com as outras.
Pra padrões "direcionais" (a conta muda de débito/crédito conforme o dinheiro entra ou sai — ex. empréstimo PJ Ferrara), use contaDirecional + histSaida + histEntrada em vez de debito/credito/hist. Pra um lançamento que sempre acompanha outro (ex. Cristiano/lucros), use companion:{debito,credito,hist}.
Cadastro — Empréstimos Sicoob
Contratos de empréstimo reconhecidos pelo número que aparece na coluna "Documento" do extrato (ex. "01916198" → contrato 1916198). "Última Parcela" incrementa sozinho a cada lançamento processado — corrija manualmente se pular um mês. Pra adicionar um contrato novo ou mudar a composição das contas (o "pernas"), use "Editar via JSON" — cada perna é {conta, lado:'D'|'C', tipo:'banco'|'fixo'|'diferenca'} ("banco" = valor pago naquele débito do extrato, "fixo" = valor sempre igual, "diferenca" = a única perna que fecha o lote, calculada sozinha).
Cadastro — Loteamentos/Parcelamentos (linhas idênticas)
Pra pagamentos que aparecem no extrato como linhas idênticas quando há mais de uma parcela do mesmo tipo no mês (mesmo histórico, mesmo valor, mesmo favorecido — ex. duas parcelas J.S Administração, lotes diferentes) — nada no extrato diferencia qual é qual, então a ordem de aparição decide: a 1ª ocorrência usa a 1ª configuração da lista "Ordem", a 2ª usa a 2ª, e assim por diante. Use "Editar via JSON" pra adicionar um novo grupo ou corrigir a ordem/contas.
